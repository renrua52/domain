Verifiablizing Research - Beyond Both of Us

Posted on 2026-10-08 In Science

一个不比 agent 更聪明的人，如何和 agent 一起，造一道足够难、可验证、难以 hack 的题目。

笔者近一个月合成了不少 Terminal-Bench-Science 或类似 benchmark 的物理方向题目。笔者本人物理学的并不深，1也没有很丰富的物理学研究经历，对于大多子领域没有了解或只有少量宽泛的了解。然而笔者认为，对于批量的造题而言，专业领域的知识并没有那么重要，反而 general 的判断能力、造题的总体方法论，才是合成质量的关键。

一方面由于个人的智力已经很难在任何领域 cover 模型了，另一方面由于生产力的需要，造题必然成为一个人机协作完成的任务。然而，借助 agent 去难倒 agent 本身，听起来略带「左脚踩右脚升天」的色彩，因而是非平凡的——其核心可以概括为：人和 agent 要如何协作地产出一个人不会2、agent 也不会3的问题。

一个最简单的 baseline 就是把 task 要求告诉 agent，然后全权交由 agent 负责产出题目。这个 baseline 存在哪些问题呢？

  1. 有明显的模式坍缩：比如 TBS 物理方向上，经常构造成「给定一组模拟的仪器相应数据，重建系统参数，然后与真值数值比对」；

  2. 模型对自己出的题目存在明显的 bias。

人类历史上，有没有「提出一个自己不会解的，但是知道一定可解的问题」的例子呢？这正是棋类。棋类的伟大之处正在于，人类通过一些简单的规则，构建了一个复杂到他们自身都无法完全理解的游戏；时至今日，我们依然有理由相信，目前最好的机器依然是非常 suboptimal 的（因为新权重总能以压倒性优势碾压旧权重）。我们于是可以自然地从中 formulate 出一个 agent task，例如：「构建一个能击败当前 KataGo 版本的围棋 AI」——如前所说，它显然可解且可验证、显然足够难、显然极难 hack。

我们能否将这样的经验迁移到更广义的任务构建上呢？注意到上面这个 task 可以抽象为一个一般的形式：要求给出一个可被评测的系统，使得该系统的性能超过某一个标准。不难发现，许多常见的 benchmarking 都属于此类：

  • 优化 NanoGPT 达到指定 loss 的耗时；

  • 优化 GPU kernel，直接评测 wall clock time。

在自然科学的一些分支中，这个一般形式是直接可迁移的——例如高能中有很多低维的分类问题4，设计 task 时可以让 agent 利用有限样本给出一个尽可能好的分类器，然后对分类质量指标（准确率等）设置阈值来 verify。5

相比于之前棋类的例子，这里还有一个小小的 nuance：对于棋类，我们有理由相信「性能更好的系统是存在的」，因此不需要对可解性做过多的解释；但是自然科学问题中，显然不能随便划一个超高的阈值，然后声称这就是一道能难倒模型的题目了——因为这个阈值可能是原则上就不可达到的。换言之，造题者要能给出一个 oracle，它能实现比模型的实现更优的性能。

乍一听，这又绕回到原点了：我们怎么能指望自己能够打败模型呢。但是注意：我们作为出题者，是有无限的时间和资源可以使用的；而真实评测时，模型能使用的资源是有限的。我们可以在资源无限的情况下做大量的实验，找到 best practice；这过程中我们事实上创造出了我们和模型此前都不曾掌握的「新知识」。然后我们要求模型在资源有限的情况下实现相同的性能：这正是在考验我们刚刚创造出的「新知识」是否已经被模型掌握；这显然也是一条极有价值的 RL 数据。这种资源不对称性是这类造题的核心。

具体举一个例子：比如说我们造一道物理题，限制模型只能获取 500 个数据样本，来训练一个性能尽可能优的分类器；样本应该如何选取和配比，是模型任务的一部分。在造 oracle 时，我们可以和 agent 一起探索一万种不同的配比和合成方案，找出最好的一种作为 oracle，然后用它来划定任务的 verifier 阈值。而 agent 被评测时，它需要判断出一万种方案中哪一种最优，才能获得完整 reward——可以预想，它是不太可能直接做对这个判断的。而我们作为造题者，已经获知了这个判断的答案，因此我们能难住模型，也能让模型从这道题中学到东西。

本质

Posted on 2026-09-13 In Journal

我和一个过去的朋友之间有一种默契：即使通过宽泛的形容，我们也能理解到对方的意思——感冒的时候，他对我说他从鼻子里闻到了感冒的气味；连这我也能够听懂。

他常常说，「这不本质」。数学上，形容什么是「本质」常用一个词汇叫做「典范」——我很喜欢的一个定义是「我们称一个对象是典范的，如果任取两个足够聪明的数学家，他们会以相同的方式给出它」。换言之，越多人对于一样东西具有默契，它就越本质；我猜，两个人之间意义相通的词汇越多，他们的默契也就越好。

诊断书上说，我是一个喜欢穷思竭虑的人。我觉得这不本质。我总觉得，面对困惑、慌乱、恐惧的唯一的工具，就是彻底的了解——完整的解释可以使一样东西失去使人着迷的魔力。

诊断书上说，我的社交能力有所欠缺。我觉得这不本质。对我而言，成为一个足够合群的人并不是一个成立的目的。我不明白人们为什么要隐藏所有人心知肚明的事实；我喜欢的方式是把真话用比直接更直接的方式说出来，人们反而会怀疑，这更让我觉得有趣。

诊断书上说，他确诊了中度抑郁。他觉得这是本质的。

我花了许多时间相信一切都存在一个本质的解释，甚至相信这个解释可以被言说；现在我也不确定。我试过了直截了当地问「你在想些什么」，并没能得到满意的答案；也许那人没有什么可说的，也许并不能说出口。我们终究是通过表象进行交流的，就像蒸馏模型吐出的句子；我们应当期待这能让我们触及本质吗？我猜，也许一些人并不由某一种稳定的精神本质生长出来；人类是易变且易逝的。我怀疑，许多人声称的价值观远非静态的准则，也许只是对自身欲望行为的合理化；而这种合理化的边界是随着欲望的变动而可以改变的。

我们是为了原谅自己而原谅世界吗？

一年前的生日，我收到他的礼物。我们绝交时，我几乎是不在乎的。我没有想到再次提起他时我痛哭流涕。我愈发感到过去的人的好，这意味着我过的越来越差了吗？

祝你像此物所展示的函数那样，即使渺小，也可以非平凡。

豆腐味能够存在是一个奇迹：倘若没有古人想起把豆浆存下，发明点卤，世上就没有这种味道了。

取嫩、但不是极嫩的豆腐一整块，放冷，以小碗装。用小木勺舀起来，与大量的姜蓉同吃，嫌味寡淡则可以淋酱油。吃腻了以后，可以备盐、胡椒、辣椒粉、葱花，或各种喜欢的调料1，加一点在豆腐上，立即连调料挖一块吃掉；这样可以尝遍各种味道，和清酒的稳定感极其搭配。高级一点的话，烤过的明太子绝好。

Verifiablizing Research - Between Two Frontiers

Posted on 2026-08-11 In Science

近期，笔者在同时考虑 AI4SCI 和 AI4AI 的 benchmark 应该怎么做。事实上笔者一直认为 AI4AI 应该被视为 AI4SCI 的一个子集，因为：

  1. AI 是 Science。关于 AI 的知识目前普遍是经验性的，但这并不意味着 AI 不属于科学，科学可以是经验的；同时我们也期望着它可以更定量（physics of AI）。
  2. 研究模型是在一个完全可控的 universe 中探索（in principle，每个参数都受到研究者控制、在其观察范围之内）（by ziming），因此某种意义上是所有 AI4SCI 中最可做的一支。

所以本文将把 4SCI 和 4AI 的 benchmarking 放在同一框架下思考。

笔者的出发点是，一个好的 benchmark 需要具备的性质包括但不限于：

  1. 可验证；
  2. 够真实；
  3. 有创新；
  4. 够难。

这里 1 和 3 似乎很多时候是矛盾的。事实上很多 benchmark 都在 3 的边界游走，因为 1 需要定义一些 rubrics，但是往往 rubrics 写的越清楚就越像竞赛题（例如 frontier science 的 research subset 我觉得就和 olympiad subset 没有实质区别）。

笔者能想到的几个保证可验证性（1）的路径：

  • 只看模型 loss，同一个 setting 哪个 agent 优化到的 loss 低就牛逼。
  • 算力不对称，大算力获得可验证结果，但 agent 没办法直接模拟。4AI 和 4physics 都能做，后者用 simulator 环境。
  • 反向设计：设计出具有某个性质的系统，环境验证这个性质。

笔者能想到的保证创新性（3）的路径：

  • 做在线 bench，搜 open problem；未必很难，但是要解决它必然有旧知识到新知识的整合过程。1
  • Simulator 环境如果能跑出新的现象，就自动成为一个 valid research problem。
  • 还有就是专家参与（例如 top researcher 和 agent 的对话流，应该是一个非常高质量的数据）。参考很多 AI4SCI 已有的造题 pipeline 还是有专家参与，合成并不是太成功。2

看起来，两者重合的地方在 simulator as judge 这个路线上。

两种边界

如果真的要做 autoresearch，最终的大目标肯定是让模型输出「human knowledge 边界」之外的东西。可是现在我们的目的是评测，假如我们知道如何对这样的输出写 rubrics，其实我们或多或少预设了模型的目标。

然而我们如果退而求其次，把 autoresearch 的能力弱化为「发现自身已有知识之外的新知识」，这就给出了一些做评测的空间。例如「用爱因斯坦之前的知识 pretrain，然后测试模型是否能提出相对论」，实际上就是在测评这样一种弱化了的能力。这样一种能力并不是 trivial 的，独立发明前人发明过的东西，在智力上是很有挑战性的，而且正是很多 top researcher 曾经做过的事情，

换言之，我们不再要求模型突破「human knowledge 边界」，只要求它能突破「pretrain knowledge 边界」。这正是解读 simulator as judge 的另一种视角。

难度来源

一个需要注意到的事实是：ground truth 的生成依赖算力，并不意味着问题就是困难的。如果合成题目的流程使用了模型，需要小心地保证题目的难度来源于外部 compute 真的引入了「知识边界以外的信息」，而不是仍然来源于模型本身「把这道题设计得很好」。所以，也许理想情况下，应该先用外部 simulator 做足够多的实验、发现非平凡的现象，再以「解释或预测该现象」为题目的内容；这里注意到「依赖外部计算」只是一道题非平凡的必要但不充分条件。

一个 side note 是，在笔者制备题目的过程中，会发现：笔者使用的 coding agent 的基础模型，在测评时的表现也倾向于更好。可以确认，这并不是因为 ground truth 泄漏，但这种相关性似乎是存在的。「这种相关性是否具备普遍性」是笔者认为值得深入研究的独立问题，尤其是对于关心 posttrain 数据质量的人。

  2. 但是由于 AI4AI 具有完全可控的性质，合成也许是 promising 的。这就是 ArchitectureIQ 的基本想法。↩︎

武夫

Posted on 2026-08-06 In Food

国内的日料已经发展多年，仍然不知为何如此同质化。我几乎能够默写一个典型的日料店的菜单：牛油果沙拉、三文鱼甜虾、芥末章鱼、烤牛舌/鳕鱼、寿喜锅、鳗鱼饭、天妇罗、鹅肝手卷。即使是贵价的omakase，其卖点经常也不过堆砌海胆、金枪鱼，还有近来流行的小竹荚卷、鹅肝刨花。甚至一些数年前很优秀的店1，最近也归于此列。我倒不觉得这全然因为预制：他们往往也喜欢打现做的招牌。也许只是顾客太多，喜闻乐见成为唯一的标准吗？

那么，在北京上海以外的地方，在小巷子的路口，开一家需要预约的小店，在酒肴里放生韭菜、大肆展示蛤蜊的腥、微微烧焦鸡皮、秋刀鱼不去内脏、鸡肝不烤全熟呢？这是危险的、优雅的、没有意义的。小店里开着嗡嗡的风扇，因为「假如所有人同时点酒蒸蛤蜊的话，就会变得很热。」

第一次来这家店时，胖胖的台湾老板娘染着蓝色的头发传菜，告诉我们「今天的炭火不知为何特别小，老板在后厨拿着小扇很用力的在扇了，烤的有点慢。」这回她头发染回了黑色，看上去更规矩了；可是我更不规矩了，点了一整瓶南部美人的大吟酿。她说，这支酒原先是一对新人订的，标价520；可是新人分手了，卖给我必须打折。我不管新人怎么样，也不好讨论爱情，因为坐在我对面的是我妈，正听我高声讲着最近混迹的人群，音量有意让隔壁桌听见，仿佛为了报复我每天听着的那些难懂的话题。

酒让一餐饭有了一个支点。你吃一口鸡肉，微微烧焦的鸡皮缓缓泛起苦味；但是酒的力量如此强烈，你喝一口酒，就被强制带回这个果味甜香、平衡的支点。借此，你得以接连尝到鸡肝的脏器浓郁、新鲜蛤蜊的海腥味、松茸芯部的野性、金吉纯粹的油脂。

这里的每一道菜的每一个成分都透露着个性：关东煮里没有常见的丸子，是蔬菜、豆制品和松软的肉糕；你找不到日料店常见的小菜，这里也不卖三文鱼；甚至萝卜泥还有新鲜白萝卜的呛辣。对于我这样从不挑食的人，是极致新鲜的享受。大众点评里总会有人抱怨蛤蜊发苦，十五元一大盒的预制麻辣蛤肉家家都热销，可是这里卖需要明火煮很久的酒蒸蛤蜊。「这本来是冬季菜单，可是大家太爱吃了。」

南京的餐饮业我认为冠绝中国。因为这里有最好的烧鸟店，最好的意大利菜，最好的江鲜。因为这里没有基模厂，投资人都嫌弃这里太不上进，正说明这里有最好的生活。当然还因为坐在我对面的是那个唯一愿意吃我选的餐厅、我点的菜，微笑着听完我别处听来的高谈阔论，陪我喝酒也送我回家的人。我许愿陪这个人吃无数顿饭。

透明酒精

Posted on 2026-07-29 In Journal

幼儿园时，我每天拒绝在午睡时闭上眼，因此每天挨老师骂。现在我终于明白他们的良苦用心：睁眼的习惯几乎要将我置于死地。

无论经意与否，每当我窥见一个我不了解的世界，我定要不惜代价一探究竟，好比一定要掀开遮阳的石头看底下的蚁穴。这种欲望使我通晓了男女尚不得以见光的欲望，喝了第一口酒，纵容了自己抛弃理性三个月，也结交了功利的所有者。我知道了答案，却愈加慌乱，经过数个月才能康复；我已经习惯了这种收获成长的方式，即经历漫长的动荡收敛到一个全新的稳态——而这稳态在更大的时间尺度上依然是暂时的。这也许是下面这半句粤语歌词打动我的原因：

尽情失控

盲目一定不好，否则自然选择应当选择瞎子；所以我认为这种习惯也不算太坏。然而我也不明白人为什么见了更高的风景，不会鄙夷自己的生活；也不明白为什么见了更深的痛苦，还能够心安地受用馈赠。我的活着终究是依赖于忽略，依赖于伤亡报道的下一条是喜闻乐见的擦边视频；依赖于无知，依赖于用自己的狭隘眼光去诠释全世界的生活。

我站在五道口，这里有全世界的生活。我近来很喜欢来这里的一家有着很好的酒肴的居酒屋，配上一壶清酒1。我想一个人坐在角落里吃一份煮牛筋和一份鸡肝，花掉上一次的 50 元代金券。然而只剩下了中间的座位。事实上，我讨厌在饭馆或咖啡馆 overhear 别人的交谈。一些人尤其喜欢谈论投资这类小孩子不会自动学会谈论的话题，也就是说，你得有十足的兴趣2才能学会与他们交谈；同时他们擅长使你因为不懂得与他们交谈而自卑。五道口这里的高中生是一种可怕的存在，这些男生和女生们的性感3程度和恋爱经验均让我怀疑人生，让一个二十岁的孩子感到衰老。

人们都说要拓展眼界，不论他们自己的眼界狭窄与否。我猜这正是假日里一群一群的涌进清华园的中小学生的父母的所想；然而这一种所谓「眼界」显然是荒谬的，所以重点不在于用眼睛看。那么被迫偷听别人的谈话呢？无非只言片语，到头来还是要用自己的脑容量去拼凑一个解释；这种解释往往是相似于自己生活的。倘若解释得了便作罢；解释不了，便陷入长久的焦虑。对我有效的解决之法有三：一则不慎爱上此人；二则说服自己此人单纯是蠢；三则自己成为此人，解决一切的疑惑。法一幼稚，法二狂妄，于是法三成为我如今默认的选择。我就是这样学会喝酒的。我不知道我解释清楚了没有。

酒精是这样一种隐蔽的邪恶。我早先认为自己是不会喝醉的：我说酒后吐真言，可是我本性便爱一言不发，平时也真诚不欺，没有什么非要酒精来揭穿的。我早先也认为所有的喝酒只是为了场面或者情调，这物质本身并不会吸引我。事实上我也不曾喝醉，至少没有失去过理智，可是即便我不承认，那种屏蔽感官的感受是其他时候我所没有的——被物质影响是一种奇怪而危险的感觉，也许对于很多人来说，正是因为危险而迷人；同时也是你所不愿意承认的。

倘若我十八岁时看到这样的文字，我会感到深深的恐惧的。我会害怕自己因为没有喝过酒而错失什么东西，例如错失十八岁。我觉得我的经历中还有很多这样的例子，这种恐惧是我唯一的探索这个世界的动力吗？我并不知道这是否是一个合适的论断。

我站在五道口。我看过一个视频，讲述疫情以前这里有多少的酒吧、夜店，学生们如何在夜里的这里聚集，年轻男孩和女孩如何在这里做那些毫无新意但永远吸引人的事情，以及这一切如何消失。可是我觉得这一切的魂灵仍然在这里，只是收起了高层的灯光，退回到那些无人会注意到的极窄的门面里——五道口的很多小店都是窄条形的，像钢琴键。你在那些脏兮兮的酒吧里，听到三流驻唱歌手的嘶吼，心想你的嗓子恐怕会因为酒精变得更差吧。即使廉价也要娱乐吗？

我看到五道口的魂灵像美杜莎沿着成府路一点点逼近。我举起小小的酒杯，透过里面透明的液体看过去。我看到所有的人变成石头，天上下起灰色的雪。我应该闭上眼睛吗，还是继续允许这酒精使我看不真切呢？

污水河

Posted on 2026-07-24 In Journal

污水河，
我向你高呼求救
那一些透彻的魂灵，
那一些晦涩的星宿，
双双丢失
流成血与光，
流在污水河。

至少
把死亡治愈，
骨灰聚拢。
把永久的酒醉唤醒，
洪水结回冰。

或者
把应得的
归还给寻找的；
让撕碎的复原，
坠落的升起，
绳圈解开。

污水河，
我求你证明我的荒谬。
给我存在的理由，抑或
不存在的
你的窄而湍急处，
以我心上的松锈的死的铁索，
攀住岩缝。

任由那凉水冻结脊髓，
我祈求一个炼狱
再使它沸腾。
全部地层里的煤炭燃烧，
雪拒绝消融。

沉下
满载公平的棺椁，
填平
富含答案的淤泥。
亿万的活人苦痛着开凿
污水河。
